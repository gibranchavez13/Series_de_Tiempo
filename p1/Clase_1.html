dplyr tiene una función llamada filter(), que oculta la función del mismo nombre de la paquetería stats. Si quisiera usar la función, tendría que escribirse así:

stats::filter()

¿Cómo calculo los viajes promedio en la costa este de Tasmania?

tourism |> 
    filter(
        State == "Tasmania", 
        Region == "East Coast"
    ) |> 
    as_tibble() |>
    group_by(
        Purpose
    ) |>
    summarise(
        mean_trips = mean(Trips)
    )
# A tibble: 4 × 2
  Purpose  mean_trips
  <chr>         <dbl>
1 Business       4.24
2 Holiday       69.0 
3 Other          1.34
4 Visiting       9.19

Graficar los viajes en la costa este de Tasmania:

tourism |> 
    filter(
        State == "Tasmania", 
        Region == "East Coast"
    ) |>
    autoplot(Trips) + 
    facet_wrap(
        vars(Purpose), 
        scale = 'free_y'
    ) + 
    theme_minimal() +
    theme(
        legend.position = 'none'
    ) + 
    labs(
        title = 'Viajes por propósito en la costa este de Tasmania',
        subtitle = 'Australia',
        y = 'Viajes (miles)',
        caption = 'Datos de la paquetería `fpp3`'
    )
